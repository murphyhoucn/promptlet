# Promptlet 产品规格 v0.6

> 2026-10-30；对应软件 0.2.0。当前技术已确定：Windows 11 x64、WinUI 3、C# / .NET 10。
> 历史讨论保留在 docs；旧 Tauri 原稿只作归档，不构成当前实现要求。

## 产品目标

复制原文 → 全局快捷键 → 调用用户模型优化提示词 → 完整成功后自动复制 → 用户粘贴。工具安静常驻，无账号和中转服务，不使用 WebView 渲染界面。

## 窗口与入口

- 系统托盘常驻、单实例；默认 Ctrl + Alt + Space，可修改并检测冲突。
- 提示词窗口无原生外框、置顶、Acrylic；设置是独立普通窗口、Mica 和随主题变化的系统标题栏。
- 托盘和浮窗齿轮打开同一设置实例；关闭设置不退出。托盘退出或 --quit 正常释放请求、快捷键和图标。
- 主题支持跟随系统 / 浅色 / 深色，系统负责材质降级。

## 模板和模型

- 模板、模型均使用稳定 ID 和列表，无业务数量上限。名称 / 别名分别忽略大小写、首尾空白去重。
- 两个内置模板可改名、不可删除；恢复默认仅恢复正文。自定义模板可增删，删除当前项回退内置科研模板。
- 每个模型独立保存别名、Base URL、Key、模型 ID、流式开关；逐项测试连接。
- 列表选择只编辑草稿；“用作当前”加保存才生效。关闭设置丢弃未保存修改。
- 删除当前模型进入未配置态，不自动替换服务；删除与在途请求关联的模型时取消该请求。普通切换 / 改名只影响下一请求。
- 浮窗结果显示本次任务快照中的名称，空闲时显示当前选择。

## 请求与剪贴板

- 仅在用户触发时读取当前文本，不读取历史、不轮询。输入上限 20,000 Unicode 标量，编辑区显示计数。
- Chat Completions 兼容格式，按 SSE 事件解析或关闭流式；不自动追加 /v1、不重复追加 /chat/completions。
- HTTPS，回环 HTTP 例外；Key 非空才发送 Bearer。测试连接发送固定短文本。
- 单任务、不可变请求快照、迟到结果丢弃。完整成功、非空且正常 stop 才可提交；截断、失败、取消不自动写入。
- 原生独占访问中校验剪贴板版本和文本，用户复制新内容则不覆盖，保留手动复制。
- 总超时 60 秒、每次底层读连续停滞上限 20 秒；不自动重复请求。
- 剪贴板仍是自己上次结果时只展示，不重复优化。

## 隐藏与编辑

- 生成中暂停倒计时。结果、失败、复制被阻止、复制失败、手动取消均重新给予完整时长，默认 5 秒，可配 0–120 秒。
- 用户交互重置；编辑 / 文本拖动 / 菜单展开暂停，结束后重新计时。重复绘制不重置。
- 失焦或手动隐藏立即隐藏，请求继续；Esc 取消并立即隐藏。隐藏期间终态不抢焦点，重开给予完整阅读时间。
- 0 关闭倒计时，保留失焦和手动隐藏。
- 原文编辑需显式重新优化或 Ctrl + Enter；隐藏保留草稿，放弃编辑后恢复通常剪贴板流程。Esc 键帽隐藏，底部静态提示保留。

## 视觉与图标

- 两张原文 / 结果卡片，统一字号阶梯、圆角和间距；长名称省略并提示全文，动作按钮最小宽度稳定。
- 主按钮跟随系统强调色，品牌绿用于 Logo 与标签。内置明暗 Logo，原创四角星；参数由单源生成资源。
- 无边框应清理原生 WS_DLGFRAME 等残留并刷新非客户区，不能只隐藏描边颜色；背景铺满客户区，外部圆角交给系统。

## 数据与发布

- v2 设置与密钥映射同文件原子提交，逐项 DPAPI 当前用户加密，不存明文 Key / 正文历史。
- 读取旧格式保留模板和偏好，首次新格式保存前备份；部分 Key 失败只影响对应项；未知未来格式禁止覆盖。
- 设置显示当前实际路径，可打开目录。错误日志脱敏、限额轮转。
- 自包含发布目录、完整 ZIP、当前用户安装和卸载、SHA-256；不上传商店、不提供签名或自动更新。
- 验证应覆盖 Core、实际 DPAPI、原生控件与窗框；已验证和未验证边界分别写入 verification.md。
