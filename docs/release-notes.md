# Promptlet 0.2.2

2026-10-30，Windows 11 x64，提示词浮窗拖动修复。

- 去掉 Logo 按下时立即发送系统标题栏拖动消息的逻辑，避免点击松开后仅移动鼠标仍带动窗口。
- 页面空白、静态标题和 Logo 支持左键按住拖动；移动超过当前 DPI 的系统拖动阈值才开始移动窗口。
- 松开、取消、丢失捕获、失焦、隐藏或 Esc 清除拖动状态；移动时复查实际鼠标左键状态，防止漏收释放事件后继续拖动。
- 按钮、文本框、滚动条保留原有点击、编辑、选择和滚动；优化请求、剪贴板及倒计时策略不变。
- 新增 8 项拖动回归用例及原生移窗 / 命中区域 / 隐藏清理烟测。

# Promptlet 0.2.1

2026-10-30，Windows 11 x64，UI 修复补丁。

- 提示词窗口：原文与结果区在常态、悬停、焦点状态统一使用卡片底色，去除内部灰色矩形；保留文字选择、复制、编辑与滚动。
- 原文区按内容调整高度，空态更紧凑，长文在卡片内滚动；增加标题与卡片间距，标题支持换行。
- 设置窗口：模型和模板列表按行数收缩，最多显示四行，更多项目在列表内滚动；长名称省略并提供完整名称提示；未配置模型时显示空态说明。
- 增加对应布局、深浅主题及文本控件视觉状态的原生烟测，导出隔离数据的 XAML 预览。
- 设置关闭后忽略迟到的主题事件，避免访问已销毁的原生标题栏。
- 未改变请求、剪贴板保护、配置格式、模板/模型切换或倒计时逻辑。

部署到本机当前 Windows 用户。0.2.0 安装目录与发布包保留，可在退出新版后运行旧版回滚；两个版本共用兼容的 v2 配置，不要同时运行。

# Promptlet 0.2.0

2026-10-30，Windows 11 x64。

- 新增无限业务数量的模板与模型配置、稳定 ID、模型别名展示、逐项连接测试。
- 模板支持改名，内置项不可删除、恢复正文保留名称。
- 新增 v2 配置格式、逐模型 DPAPI 密钥、旧格式迁移备份、部分解密失败保留与未来格式只读保护。
- 生成时暂停隐藏，所有结果和错误 / 手动取消重新倒计时；保留 Esc 和失焦行为。
- 原文编辑草稿跨隐藏保留，新增字符计数和放弃编辑。
- 隐藏框架 Esc 键帽，统一两卡片、字号与间距，新增实际模型 / 模板标签。
- 修复非流式读取阶段被固定 20 秒截断的问题；流式和非流式按底层读操作检测停滞，总请求仍为 60 秒。
- 保留原生窗框修复，主题同步至设置标题栏。
- Logo 圆点改原创四角星，单源生成明暗图、SVG 和多尺寸 ICO。
- 新增安装 / 卸载入口、文件和 ZIP SHA-256、开发与使用文档、Windows DPAPI 与原生窗口烟测。

默认决策：单 Windows 用户本地安装；无商店上传或远程部署；图标参数按建议直接落地；不做模板导入导出、历史记录、自动粘贴、云同步、自动更新。真实供应商配置由使用者提供。
