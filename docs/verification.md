## 拖动手工验收

1. 通过托盘打开提示词窗口，或以 `Promptlet.exe --show` 仅展示，避免为拖动测试额外发送真实模型请求。
2. 单击 Logo 后松开，再移动鼠标：窗口位置不变。单击齿轮及隐藏图标：仍只执行各自按钮功能。
3. 在页面空白、标题或空态卡片按住左键并拖动：超过阈值后窗口移动；松开后继续移动鼠标，窗口立即停止。小幅抖动不移动窗口。
4. 在已有正文处拖动：选择文字，窗口不移动；点击编辑，在空输入框输入和选字正常；滚动条仍只滚动文本。
5. 拖动时按 Esc 或切换应用，重新唤起后移动鼠标：不继续旧拖动，必须重新按下才能开始。
