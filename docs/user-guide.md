# Promptlet 使用文档

## 安装与卸载

需要 Windows 11 x64。在 [发行页](https://github.com/murphyhoucn/promptlet/releases/tag/v0.2.2) 下载 `Promptlet-0.2.2-Setup-x64.exe`，双击并按中文向导安装。无需解压、命令行或管理员权限；默认位置为当前用户的 `%LOCALAPPDATA%\Programs\Promptlet\0.2.2`，完成后可直接打开设置或从开始菜单启动。`Source code` 和 `source.zip` 是开发者源码，不是安装包。

从 Windows“已安装的应用”中卸载 Promptlet。EXE 安装版也可运行安装目录的 `unins000.exe`；卸载保留 `%LOCALAPPDATA%\Promptlet` 下的配置。当前版本未签名，Windows 可能显示 SmartScreen 提示，请确认来自官方发行页；无自动更新。

仍提供 `Promptlet-0.2.2-win-x64.zip`：完整解压后用 Install.cmd 安装（其卸载脚本为 Uninstall.ps1），或直接打开 App/Promptlet.exe 便携运行。便携模式必须保留整个 App 文件夹。此前用脚本安装的用户可运行 EXE 覆盖安装，不需要删除个人配置。

## 模型连接

托盘右键设置，或点击提示词窗口齿轮。点击模型区域“新建”，填写别名、接口地址、密钥、模型 ID；开启或关闭流式。地址包含服务商要求的前缀，例如 /v1，程序只追加 /chat/completions。完整接口地址也可识别。HTTPS 为默认要求；本机服务允许 HTTP 且可以无 Key。

“测试此模型”只测试当前编辑项，使用固定短文本，不读取剪贴板。点击“用作当前模型”后再保存才生效。新建多个模型时，各项 Key 和其他字段相互独立；列表选择只是编辑对象，不等于正在使用。

删除当前模型后必须手动选择另一项并保存，不会自动切换服务。未完成的关联请求会在保存删除后取消；已经复制的结果不回滚。

## 优化模板

列表提供通用和科研项目两套内置项，可改名和正文，不能删除。新建自定义模板可以自由编辑和删除；名称不允许重复。选择模板后点击“用作当前模板”再保存。

“恢复内置正文”只恢复出厂正文，保留名称。删除正在使用的自定义模板后回退内置科研项。没有业务数量上限，但建议按实际用途组织条目。

## 日常流程

复制一段文字，按 Ctrl + Alt + Space，等待结果。成功会写回剪贴板，回到原应用粘贴。不需要按 Enter 确认，不会自动操作其他应用。

生成时浮窗不会因为倒计时自动消失；完成、失败或手动取消后开始新的倒计时。默认 5 秒，在设置中可改为 0–120 秒。0 只关闭倒计时，点击窗口外 / 切换应用仍会隐藏。

点击隐藏或切到其他应用，请求继续；Esc 会取消并隐藏。等待时复制新内容会阻止自动覆盖，结果仍可手动复制。再次唤起自己的上次结果只显示、不重复发送。

移动窗口：在页面空白、静态标题、Logo 或没有正文的只读卡片内按住鼠标左键并拖动，松开停止。单击再松开后移动鼠标不会移动窗口；轻微抖动不触发拖动。文本框有内容或处于编辑模式时，拖动仍用于选择文字；按钮、滚动条保留原有操作。

## 编辑与草稿

点击原文“编辑”，显示字符计数，上限 20,000 个 Unicode 标量。编辑不会自动发请求。点击重新优化或 Ctrl + Enter 提交；点击放弃编辑或 Esc 结束编辑。编辑时暂停倒计时。

隐藏后重新唤起保留内存草稿；此时快捷键只恢复编辑窗口。结束或放弃编辑后，下一次快捷键恢复读取剪贴板。关闭进程不保存草稿或结果历史。

## 设置与隐私

设置底部显示当前配置文件路径，可以打开目录。模型密钥按当前 Windows 用户加密保存；不要公开配置和备份。旧版数据可读取并在第一次保存新格式前建立 v1 备份。

密钥解密失败只影响对应模型；重新填写或点击“清除此配置的密钥”。原密文在未明确替换或清除前保留。无法读取整个配置时软件拒绝覆盖，提示检查原文件或备份。

## 常见问题

- **快捷键无效**：用托盘设置检查组合是否冲突。冲突时保存失败，保留旧绑定。
- **模型已填写但不能用**：用作当前模型并保存，核对模型 ID、Key、路径前缀和额度。
- **返回错误或没有复制**：检查结果是否截断、网络是否中断或剪贴板是否更新；失败不会写入不完整文本。
- **设置没生效**：设置窗口的关闭按钮不会自动保存；别忘了保存。
- **窗口消失但程序还在**：这是托盘常驻工具；从托盘右键退出才会结束进程。
- **找不到文件**：以设置页展示路径为准；某些启动宿主可能重定向 AppData。
- **程序移动后自启失效**：安装器会更新已启用路径；便携方式移动后重新切换开机启动开关并保存。
- **包很大**：包内包含桌面运行时，用户不必另装 SDK；磁盘大小不等同于运行内存。
